# Purpose

Defines basic information-security practices for employees, contractors, and approved vendors.

# Access Control

Access to customer information, source code, cloud systems, and financial systems must follow business need and minimum required access.

# Authentication

Employees must use strong passwords and multi-factor authentication where available. Shared credentials are prohibited. API secrets must be stored in approved secret-management systems.

# Customer Data

Customer information may only be accessed for legitimate business purposes and must not be copied to personal devices or unauthorized channels.

# Software Development

Code changes should be reviewed before production deployment. Sandbox environments and test data should be used for development and integration.

# Security Incidents

Suspected unauthorized access, lost credentials, malware, data exposure, or similar events must be reported promptly.

# Vendor Security

Third-party vendors handling company or customer information should be evaluated for security and confidentiality controls.
